# ATC — contrôle aérien vocal pour Microsoft Flight Simulator 2024

ATC vous guide de la clairance jusqu'au parking, à la voix : vraies fréquences, phraséologie
française ou anglaise, pistes réellement en service, trafic réel et carte de votre route.

## Télécharger

👉 **[Télécharger la dernière version](../../releases/latest)** — fichier `ATC-Setup-x.y.z.exe`

Une fois installé, ATC se met à jour tout seul : à chaque nouvelle version, une fenêtre vous
montre ce qui a été ajouté, corrigé ou retiré.

## Configuration requise

- Windows 10 ou 11 (64 bits)
- Microsoft Flight Simulator 2024 sur PC
- Une connexion Internet
- Conseillé : un compte SimBrief

## Installation

1. Téléchargez `ATC-Setup-x.y.z.exe` depuis la page des versions.
2. Lancez-le. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur
   « Informations complémentaires » puis « Exécuter quand même ».
3. Lancez MSFS 2024, puis ATC, chargez votre plan de vol SimBrief et contactez la Délivrance.

Si vous activez le **Trafic réel** d'ATC, coupez le trafic live de MSFS (Options > Trafic).

---
ATC est réservé à la simulation : ce n'est ni un produit Microsoft, ni un service de contrôle aérien réel.
