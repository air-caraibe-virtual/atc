Ajouter l'IA dans ATC

L'IA a besoin d'une « clé API » : un code personnel qui permet à ATC d'utiliser une intelligence artificielle en ligne. Choisissez un fournisseur ci-dessous, suivez les étapes, puis collez la clé dans ATC.

  1. Ouvrez la page des clés Groq
  2. Connectez-vous : « Sign in » avec un compte Google ou une adresse e-mail. C'est gratuit, aucune carte bancaire demandée.
  3. Créez la clé : cliquez sur Create API Key, donnez-lui un nom (par exemple « ATC »), puis Submit.
  4. Copiez la clé qui s'affiche (elle commence par gsk_). Attention : elle n'est montrée qu'une seule fois.
  5. Revenez dans ATC et cliquez sur 📋 Coller à côté de « Clé API ». Le fournisseur se règle tout seul.
  6. Cliquez sur « Tester la clé » : « ✅ La clé fonctionne » et c'est terminé.
  1. Ouvrez la console Claude
  2. Créez un compte ou connectez-vous.
  3. Ajoutez un peu de crédit dans Billing (5 € suffisent pour des centaines de vols : un message coûte une fraction de centime).
  4. Créez la clé : Create key, nommez-la « ATC », validez.
  5. Copiez la clé (elle commence par sk-ant-). Elle n'est montrée qu'une seule fois.
  6. Revenez dans ATC, cliquez sur 📋 Coller, puis sur « Tester la clé ».
  1. Ouvrez la page des clés OpenAI
  2. Créez un compte ou connectez-vous.
  3. Ajoutez un peu de crédit dans Billing (quelques euros suffisent).
  4. Créez la clé : Create new secret key, nommez-la « ATC ».
  5. Copiez la clé (elle commence par sk-). Elle n'est montrée qu'une seule fois.
  6. Revenez dans ATC, cliquez sur 📋 Coller, puis sur « Tester la clé ».

🔒 La clé reste uniquement sur votre PC : ATC ne l'envoie qu'au fournisseur choisi. Ne la partagez avec personne (même pas sur Discord). Si vous pensez qu'elle a fuité, supprimez-la sur la page du fournisseur et créez-en une nouvelle.

Paramètres

Intelligence artificielle (facultatif) Comprend tout ce que vous dites, répond comme un vrai contrôleur, gère les urgences et joue le copilote. Au choix : l'IA intégrée (gratuite, sans compte, sur votre PC), Ollama (gros PC), ou une IA en ligne avec votre propre clé (Groq gratuit, Claude ou OpenAI payants à la fraction de centime).
Utilise des services d'IA publics et gratuits, sans compte ni clé. Rien à installer et rien qui tourne sur votre PC. Ils sont limités en nombre de messages et sans garantie : s'ils sont saturés, ATC revient à sa compréhension classique. Pour plus de fiabilité, prenez l'IA intégrée ou Groq.
Tourne entièrement sur votre PC, hors ligne. Comprend très bien les demandes, répond plus simplement qu'une IA en ligne. 2 à 5 secondes par message, 16 Go de mémoire conseillés.
Ollama est un logiciel gratuit qui fait tourner de grosses IA sur votre carte graphique (attention à la mémoire vidéo utilisée par MSFS).
